# gil wiki — 내비게이션 허브

gil(GIt for Language model) 지식의 진입점이다. LLM이 **필요한 페이지만 골라** 읽도록
쪼개져 있다 — 통째로 읽지 말고, 지금 하려는 일에 맞는 페이지로 바로 가라. 각 페이지는
서로 이어진다.

> 웹에서 이 wiki를 참조한다면 루트의 [llms.txt](../../llms.txt)가 같은 index를 절대 URL로
> 제공한다(사람이 에이전트에게 URL 하나를 건네는 진입점).

## 무에서 시작 — `gil start`

빈 폴더(혹은 gil 세계가 없는 저장소)에서 시작한다면 단 한 명령이면 된다:

```
gil start
```

`gil start` 는 **온보딩의 다음 한 칸을 실제로 밟는다.** 부를 때마다 한 칸씩 나아가고,
끝날 때까지 반복해서 부르면 된다:

1. **세계를 세운다** — 대문 커밋(CLAUDE.md 부트스트랩 포인터) · `refs/gil/global` 초기화 ·
   존재의 방 · refspec 등록·push. (이 칸만 따로 하려면 `gil init [--name <이름>]`.)
2. **이름을 요구한다** — `gil start --name <네가 지은 이름>`. 빈 칸이지 기본값이 아니다.
3. **정체성을 요구한다** — `gil start --identity <파일> --will <파일>`.
4. **사람에게 먼저 묻는다** — 개시 인터뷰. 무엇을 하려는지, 무엇이 관측되면 풀린 것인지.
   체인보다 **앞**이다(목적과 기준은 쌍으로만 태어나므로).
5. **그 답을 인용해 체인을 열라고 한다** — 질문 번호까지 짚어서.

`gil start --status` 는 밟지 않고 지금 어느 칸인지만 본다.

**판단은 대신하지 않는다** — 이름·정체성·목적은 도구가 지어낼 수 없는 것이라, 그 자리에서
멈추고 무엇이 비었는지만 말한다. 도구가 채우면 각인이 아니라 위조다.
자세히는 [존재와 기억](existence.md).
