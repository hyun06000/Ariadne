# `.mcpb` 번들의 원본

이 폴더의 `manifest.json` 이 **Claude Desktop 확장(`.mcpb`) 매니페스트의 진실원**이다.

## 왜 여기 있나

2026-08-11까지 이 매니페스트는 저장소 어디에도 없었다 — 번들을 구울 때마다 손으로 썼다.
그래서 설치된 확장과 저장소의 상태가 갈렸고, 무엇이 배포된 판인지 알 방법이 없었다.
두 자리에 같은 것을 적으면 한쪽이 낡는데, 여기서는 **한쪽이 아예 없었다.**

## 굽는 법

```
mcpb validate manifest.json
mcpb pack .
```

(`@anthropic-ai/mcpb@2.1.2` 로 확인했다.)

번들에는 `server/gil` 로 그 플랫폼의 바이너리를 넣는다 —
`scripts/release-build.sh <version>` 이 낸 것을 쓴다.
`compatibility.platforms` 는 **그 번들에 실제로 실린 바이너리**를 말한다.
다른 플랫폼용 번들을 구울 때는 그 값도 함께 바꾼다(안 바꾸면 매니페스트가 거짓말을 한다).

## 계기는 여기 없다

`GIL_MCP_LOG` · `GIL_UI_PROBE` 는 **진단용이라 배포판에 넣지 않는다.**
켜야 할 때는 설치된 확장의 `manifest.json` 을 손으로 고치거나(그 기계 한 대만 바뀐다),
저장소 안 스위치(`.git/gil/ui-probe`)를 쓴다.
켠 채로 릴리스하면 모든 세션이 매 호출마다 진단을 하고, 프레임 로그에는 저장소 경로가 실린다.

## 디렉터리 등재에 남은 것

- [ ] **아이콘** — `icon` 항목이 아직 없다. 없는 파일을 가리키면 `mcpb validate` 가 죽고,
      무엇보다 이 저장소의 규칙(가리키는 것이 실재한다)을 깬다. 파일이 생기면 그때 넣는다.
- [ ] **스크린샷 3~5장**(MCP App 은 필수) — PNG · 가로 1000px 이상 · **앱 응답만 크롭**
      (프롬프트를 넣으면 안 된다) · 각 장에 짝이 되는 프롬프트 텍스트를 따로 낸다 · 영상·GIF 불가.
- [ ] **공개 문서** — 발행일까지 블로그나 도움말 글이 하나 있어야 한다.
- [ ] **테스트 계정 / 리뷰어 안내** — 로컬 도구라 계정은 없지만, 리뷰어가 끝까지 밟을 수 있는
      데모 저장소와 절차를 준비한다.
- [ ] **툴 설명의 명령형** — 심사가 "Claude 의 행동을 지시하는 설명"을 기각한다.
