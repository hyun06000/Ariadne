# gil app 명세 — 화면이 앱 안에 산다

**이 문서는 표면의 명세다. 문법의 명세가 아니다.**
체인·사이클·스텝의 문법, 커밋 트레일러, 층, fsck 는 `project/gil-v3-redesign/SPEC.md` 가
그대로 규범이고 **이 문서는 거기에 한 글자도 손대지 않는다.** gil 은 여전히 git 의 얇은
랩퍼이고, 진실원은 여전히 커밋 그래프다. 바뀌는 것은 **사람이 그것을 보고 답하는 자리**뿐이다.

---

## 1. 왜 — 우리가 도망친 것과 도망칠 곳

브라우저 뷰어를 버린 이유는 그림이 나빠서가 아니라 **관리 비용** 때문이었다(상현님):

- 사람이 `127.0.0.1:8790` 이라는 날 주소를 받아들고 뭔지 몰라 넘어갔다(윈도우 실사용).
- 창을 닫으면 다시 여는 길이 없었다 — 포트는 저장소마다 다르고 사람은 그걸 외우지 않는다.
  "다시 보고 싶다"가 **주소를 찾는 일**이 됐다(v3.57.0 이 런처까지 만들어 겨우 덮었다).
- 포트가 충돌하면 남의 뷰어를 열었고(v3.48.0 의 `/whoami`), 화면에 정체가 없어 사람은
  남의 그래프를 보며 자기 것이 비었다고 오진했다(#110).

**이 셋은 전부 "우리가 백엔드 서버를 하나 더 운영한다"에서 나온다.** 비개발자에게 포트와
프로세스 수명을 맡길 수는 없다. 그래서 MCP Apps 다 — 서버가 `ui://` 리소스로 HTML 을 내면
**호스트가 자기 안의 샌드박스 iframe 에 직접 렌더한다.** 주소도, 포트도, 브라우저도 없다.

> **규범:** 이 명세가 만드는 어떤 것도 사람에게 URL·포트·프로세스를 보여주지 않는다.
> 아래 §6 의 개발 고리는 **개발자 전용**이며 제품 표면이 아니다.

## 2. 표면 — Claude Desktop 이 MVP다

2026-08-10 실측. 추측이 아니라 바이너리와 번들을 읽어 확인한 것이다.

| 표면 | MCP 클라이언트 | MCP Apps | 여는 모드 | 카드 |
|---|---|---|---|---|
| **Claude Desktop 채팅** | `claude-ai 0.1.0` | 선언함 | **`["inline","fullscreen"]`** | 뜬다 |
| Desktop 로컬 에이전트 모드(Epitaxy) | `claude-code 2.1.222` | — | `["inline"]` (하드코딩) | — |
| Claude Code CLI | `claude-code 2.1.222` | **구현 자체가 없음** | — | **영영 안 뜸** |

- CLI 바이너리에 `io.modelcontextprotocol/ui`·`text/html;profile=mcp-app`·`resourceUri`·
  `_meta.ui` 가 **각각 0회**다. 아는 확장 목록에 `ui` 가 없다.
- 그 표면은 elicitation 을 **선언은 하지만 폼이 안 선다**(`gil_start` 로 실제로 밟아 확인).
  즉 카드도 폼도 없고 남는 통로는 대화뿐이다 — gil 이 지키는 단 하나가 거기서 무너진다.
- 호스트의 표시모드 판정에 **제스처 검사는 없다**: `r = availableDisplayModes ?? ["inline"];
  return r.includes(mode) ? grant : {mode: 현재}`. 목록이 전부다.

**그래서 MVP 표면은 Claude Desktop 채팅이다.** 카드가 거기 있고, 풀스크린이 거기 있고,
무엇보다 **설치가 드래그 한 번**이다(§5).

### 2.1 끝까지 밟아서 확인했다 (2026-08-10, `.mcpb` 실사용)

명세를 쓴 그날 저녁에 `.mcpb` 를 구워 Claude Desktop 에 설치하고 **풀스크린을 실제로 띄웠다.**
이 저장소가 여덟 번 다른 얼굴로 막혔던 자리다 — 이제 밟았다.

| 밟은 것 | 결과 |
|---|---|
| `.mcpb` 설치 (설정 → Extensions) | ✅ `Connected to gil (29 tools)` · `announcing gil: 25 tool(s)` |
| 확장이 맥에서 직접 도는가 | ✅ `Using basic execution ... server.type is "binary"` — 샌드박스 아님 |
| **Cowork · 로컬 에이전트 모드** | ❌ **확장의 툴이 안 간다**(그 대화는 `local_…` 세션이고 MCP 는 CLI 가 붙인다) |
| **일반 채팅** | ✅ `resources/read ui://gil/status` — **호스트가 카드를 그린다** |
| 저장소 자리 | ❌ roots 를 안 준다 → `/` 에 섬. **§4.1 의 전제가 실측으로 확인됐다** |
| **풀스크린** | ✅ **사람이 버튼을 눌러 커졌다** |

**Cowork 는 이 구조로 닿지 않는다.** 플러그인 설치 창이 `.zip`/`.plugin` 만 받고, 그 경로로
붙으면 클라이언트가 다시 CLI 가 되어 MCP Apps 가 없다. MVP 를 일반 채팅으로 잡은 것이 맞았다.

**그리고 계기는 이 표면에서 필요 없다.** 이번 판은 `GIL_UI_PROBE=1` 을 켜고 쟀지만, 호스트의
판정은 `availableDisplayModes.includes(mode)` 하나이고 그것이 **승인했다** — 즉 이 표면은
목록에 `fullscreen` 을 넣어 준다(번들에서 읽은 `["inline","fullscreen"]` 과 일치). 그러니
배포용 매니페스트에서 계기를 **뺀다**(§5.3).

**실패한 것을 잘못 읽을 뻔했다.** 채팅에서 처음 부른 gil 이 죽었을 때 첫 해석은 "샌드박스라
git 이 없다"였다. 확장 바이너리를 `cwd=/` 로 직접 돌려 같은 문구를 재현해 보니
`fatal: … 깃 저장소가 아닙니다` 였다 — **git 이 없는 게 아니라 어느 폴더인지를 모르는 것**이다.
둘을 안 갈랐으면 표면 전체를 버릴 뻔했다. 재현할 수 있는 것은 재현해서 가른다.

## 3. 구조 — 이음매는 언어가 아니라 빌드 시점에 있다

```
  TS + Vite (View)                    Go (gil)
  ──────────────────                  ─────────────────────────────
  공식 SDK                            git 의 얇은 랩퍼 · 문법 · fsck · 층
  @modelcontextprotocol/ext-apps      MCP 서버(stdio + streamable HTTP)
  타입 · 핫리로드 · 컴포넌트
          │
          │ vite build --single-file
          ▼
     단일 HTML  ──go:embed──▶  gil (정적 단일 바이너리, git 만 있으면 됨)
```

**왜 이 자리인가.** 2026-08-10 하루의 결함이 거의 전부 한 곳에서 나왔다 — **화면이 Go 원시
문자열 안에 손으로 짜여 있었다**:

- 핸드셰이크 필드 이름을 틀려 `-32603`(옛 이름 `{appCapabilities, clientInfo}`)
- `structuredContent` 가 `content` 를 가려 도착 고지·버전 문의·상태 줄이 모델에게 한 글자도
  안 닿음
- 그래프 브리지에 **응답을 받는 자리가 아예 없어** 청한 결과를 영영 모름
- 주석의 백틱 하나가 Go 원시 문자열을 깨뜨림

**넷 다 공식 SDK 를 썼으면 안 났다.** 반대로 서버 쪽은 아팠던 적이 없다 — 리소스 등록,
`_meta.ui.resourceUri`, 확장 선언은 이미 옳게 돌고 있다. 그러니 **TS 는 화면만 맡는다.**

**런타임에 Node 를 요구하지 않는다.** View 는 빌드 산출물이고, 산출물은 바이너리에 박힌다.
이 결정의 전부는 §5 에 있다 — 산출물이 둘이 되는 순간 "더블클릭 한 번"이 깨진다.

### 3.1 Go 가 계속 하는 일

- git 자식 프로세스의 유일 관문(`gitCommand`) · 자리를 값으로 드는 것(`repoDir`)
- 체인·사이클·스텝 문법, 승인/기각, 층, 이주, fsck
- MCP 서버: 툴·리소스·`ui://` 제공, stdio 와 HTTP 두 전송
- **그래프의 레이아웃 계산**(좌표·레인·간선). 이건 값이 큰 자산이라 남긴다.

### 3.2 TS 가 새로 맡는 일

- View 전부: 상태 카드, 개시 인터뷰 폼, 승인·기각, 갈래 비교, 그래프 렌더, 자리 고르기
- 호스트와의 프로토콜 전부(`ui/initialize`·`host-context-changed`·`request-display-mode`·
  `ui/message`·`tools/call`) — 손으로 짜지 않고 SDK 의 `App` 을 쓴다

### 3.3 둘 사이의 계약

**앱 전용 툴의 `structuredContent`가 계약이다.** 별도의 `--json` CLI 계약을 먼저 만들지
않는다 — MCP 가 이미 그 통로다. 다만 규칙 둘을 못박는다(둘 다 값을 치르고 배운 것이다):

1. **앱 전용 툴**(`_meta.ui.visibility: ["app"]`)은 `structuredContent` 로 데이터를 낸다.
2. **모델이 보는 툴**은 `content`(텍스트)를 낸다. 이 호스트는 `structuredContent` 가 있으면
   그것만 모델에게 주므로, 둘을 한 툴에 섞으면 모델이 눈이 먼다.

> 나중에 TUI·다른 화면이 붙을 때를 위해 `gil <명령> --json` 을 따로 낼 수 있다. **지금은
> 안 만든다** — 쓰는 사람이 없는 계약은 낡는다.

## 4. 화면 명세

### 4.1 첫 칸 — 어디에 만들까 (이것이 제일 비싼 질문이다)

Desktop 채팅은 **roots 를 주지 않는다.** 그래서 지금까지 "어느 폴더냐"가 에이전트에게
떠넘겨져 있었고, 그 결과 `/` 에 저장소를 세울 뻔했다(2026-08-10, 상현님이 되물어 준 덕에
안 났다). **비개발자에게 절대경로를 묻는 순간 그 흐름은 끝난다.**

그래서 세계를 세우는 첫 화면이 이 일을 한다:

- gil 이 **기본 자리를 제안한다**: `~/Documents/gil/<프로젝트 이름>`
- 사람은 **이름만** 정한다. 경로는 아무도 치지 않는다.
- 다른 자리를 원하면 고를 수 있다(호스트가 파일 선택기를 못 열면 붙여넣기 칸).
- **승낙은 버튼이다.** 문법의 "어디에 만들지는 언제나 사람이 정한 것이 되게"가 여기서
  처음으로 실제 UI 를 갖는다.
- `/` 와 홈 자신은 계속 거부한다(프로젝트를 **담는** 자리지 프로젝트가 아니다).

**지어졌다**(2026-08-10). 저장소를 못 찾은 화면이 곧 **시작하는 화면**이다 — 이름 칸 하나와
버튼 하나, 그리고 치는 동안 따라오는 자리 미리보기. 누르는 자리는 앱 전용 툴
`gil_start_here` 로 따로 뒀다: `gil_start` 의 `confirmed` 는 *"에이전트가 사람에게 물어
승낙받았다"* 는 **전해 들은 보고**지만, 여기 오는 것은 **사람이 직접 누른 것**이라
한 칸에 적으면 기록이 거짓이 된다(구분되는 것은 구분해서 적는다).

그리고 여기서 **없는 폴더를 만든다.** 지금까지 gil 은 없는 경로를 절대 만들지 않았는데,
그 규칙의 이유는 "어디에 만들지는 언제나 사람이 정한 것이 되게"였지 폴더 생성이 위험해서가
아니었다. 사람이 이름을 적고 버튼을 눌렀으면 **그건 정한 것이다.** 대신 자리의 성질은 그대로
본다 — `/`·홈 자신·홈 바깥은 거부한다(홈 바깥에 만들려면 `repo` 인자로 명시하는 길이 있다).

### 4.2 나머지 화면

| 화면 | 하는 일 | 이미 있는 것 |
|---|---|---|
| 상태 카드 | 지금 어디까지 왔나 · 사람이 나설 자리 | Go 렌더러 → TS 로 |
| 개시 인터뷰 | 질문지 한 벌이 **한 화면에**, 몇 개 중 몇 번째, 답은 미리 안 채움 | 문법·저장 완비 |
| 승인 · 기각 | 버튼이 진짜 명령을 돈다(`tools/call`) | 완비 |
| 삭제 승인 | prune 승인·철회 | 완비 |
| 갈래 비교 ⚖ | 형제 가설을 나란히 | 완비 |
| 전체맵 · 계보 | 레이아웃은 Go, 그림은 TS | 레이아웃 완비 |

### 4.3 풀스크린

정본 패턴을 따른다 — `availableDisplayModes` 에 `fullscreen` 이 있을 때 **버튼을 보이고**,
사람이 누르면 그때 청한다. Desktop 채팅은 목록에 넣어 주므로 **버튼이 계기 없이 뜬다.**
전체맵은 크게 볼 것이고 상태 카드는 곁에 둘 것이다(pip).

## 5. 배포와 설치 — 여기가 제품이다

> **"비개발자용"은 쓰기 쉽다는 뜻만이 아니다. 설치가 쉬워야 한다는 뜻이다**(상현님).

### 5.1 산출물은 **하나**다

플랫폼당 **정적 단일 바이너리 하나**. View 는 그 안에 박혀 있다. Node 도, Python 도,
`node_modules` 도 없다. 필요한 것은 `git` 하나뿐이다.

지원 타깃은 기존 규범 그대로 5개(darwin amd64/arm64 · linux amd64/arm64 · windows amd64) —
`project/gil-v3-redesign/SPEC.md` 의 '지원 플랫폼' 절이 단일 진실원이다.

### 5.2 설치 = 파일 하나를 앱에 떨어뜨린다

Claude Desktop 은 **`.mcpb`(구 `.dxt`)를 파일 선택기와 드래그 앤 드롭 양쪽으로** 받는다
(앱 번들에서 확인). 그러니 비개발자의 설치는 이렇다:

```
gil-<버전>-<플랫폼>.mcpb  를  Claude 창에 끌어다 놓는다.  끝.
```

터미널 없음 · 경로 입력 없음 · 포트 없음 · `PATH` 없음.

**규범:** 설치 안내에 터미널 명령이 한 줄이라도 필요하면 그 배포는 실패한 것이다.
(개발자용 `install.sh`·`go install` 은 계속 두되, **그것이 기본 경로가 아니다.**)

### 5.3 `.mcpb` 의 내용

공식 도구(`@anthropic-ai/mcpb` v2.1.2)의 스키마와 템플릿으로 확인한 형태다. 실제로 구워
설치까지 밟았다(§2.1).

```json
{
  "manifest_version": "0.3",
  "name": "gil", "display_name": "gil", "version": "3.58.4",
  "description": "…", "author": { "name": "…" },
  "server": {
    "type": "binary",
    "entry_point": "server/gil",
    "mcp_config": { "command": "${__dirname}/server/gil", "args": ["mcp", "serve"] }
  },
  "compatibility": { "platforms": ["darwin"] }
}
```

- `${__dirname}` 은 MCPB 가 설치 경로로 치환한다(`mcpb init` 이 `binary` 에 쓰는 형태 그대로).
- 굽기·검증: `mcpb validate manifest.json` → `mcpb pack .`. 파일은 **매니페스트 + 바이너리 둘뿐**,
  7.3MB.
- 플랫폼별로 따로 굽는다(한 파일에 5타깃을 다 넣으면 75MB 가 된다).
- **애드혹 서명으로 통과했다.** 다만 앱에 `Require signed extensions` 설정이 있으므로,
  배포판은 정식 서명을 갖춘다. `Allow desktop extensions` 가 꺼져 있으면 설치 자체가 막힌다.
- **`env` 에 계기를 싣지 않는다.** 재는 판에서만 `GIL_UI_PROBE=1` 을 넣었고, 이 표면은
  계기 없이도 풀스크린 버튼이 뜬다(§2.1).

### 5.4 이미 값을 치러 배운 것

- **표면마다 검사가 다르다.** 같은 zip 을 Claude Code 는 통과시키고 claude.ai 호스팅은
  거부했다 — `bin/` 이 예약 자리였다. 한쪽에서 됐다고 다른 쪽에서 된다고 가정하지 않는다.
- **macOS 는 `cp` 로 설치하면 서명이 깨져 SIGKILL 한다.** 배포 자산은 서명을 갖춰 낸다.
- 버전은 한 값에서 둘로 나온다(각인 `v3.x.y` / 매니페스트 `3.x.y`). 안 가르면 handoff 가
  "최신보다 앞선다"고 거짓말한다 — 실제로 그랬다.

## 6. 개발 고리 — 개발자 전용, 제품 아님

공식 저장소의 `examples/basic-host` 가 **브라우저에서 도는 진짜 MCP Apps 호스트**다.
2026-08-10 에 이 기계에서 실제로 띄워 툴 호출·UI 렌더·UI→서버 재호출까지 확인했다.

```
basic-host 8080  ──  sandbox 8081  ──  gil --http :3001/mcp
```

- Go SDK 에 `NewStreamableHTTPHandler` 가 있으므로 **gil 이 그대로 붙는다.** 새 서버가 필요 없다.
- 그래서 `gil mcp serve --http <포트>` 를 **개발용 전송으로** 연다.
- View 를 고치고 브라우저를 새로고침하면 끝이다 — Claude 재시작이 사라진다.

> **이 고리는 사람에게 주지 않는다.** localhost 와 포트는 우리가 §1 에서 도망친 바로 그것이다.
> `--http` 는 안내에서 개발자 전용으로 표시하고, 비개발자 경로 어디에도 나타나지 않는다.

설치 함정 하나(실측): ext-apps 저장소는 bun 을 요구하는데 `npm install` 이 그 앞에서 죽는다.
`npm install --ignore-scripts` → `npm install --ignore-scripts bun` →
`cd node_modules/bun && node install.js` 로 넘는다.

## 7. 수용 기준 — 타이타닉 생존자 문제

새 구조가 옳은지는 **하나의 판을 끝까지 밟아** 증명한다. 소재는 타이타닉 생존자 문제다:
정답이 알려져 있고, 문제의 전부가 **가설을 세우고 재고 판정하는 것**이라 gil 을 보여주기에
맞다. 모델의 정확도를 자랑하는 예제가 아니다 — **사고의 이력이 화면에 서는 것**이 전부다.

한 화면에 이렇게 선다:

```
무엇을 알아내려 하는가   "누가 살아남았고 왜인가"        ← 사람이 쓴 문장 그대로
성패 기준               "설명이 데이터로 반증 가능해야"   ← 사람이 쓴 문장 그대로
갈래 ⚖
  ① 성별이 갈랐다        가설·반증조건·측정·판정  [승인][기각]
  ② 객실 등급이 갈랐다   가설·반증조건·측정·판정  [승인][기각]
  ③ 나이가 갈랐다        ⌖ 아직 안 쟀다           [재기]
벽의 지도               ②는 ①에 흡수 — 1등석 여성 비율이 교란
```

**통과 조건 여섯. 하나라도 못 넘으면 이 명세가 틀린 것이다.**

1. **설치가 드래그 한 번이다.** 터미널·경로·포트가 한 번도 안 나온다.
2. **자리를 사람이 정한다.** 절대경로를 아무도 안 친다.
3. **사람의 문장이 옮겨쓰기 없이 들어간다.** 화면의 입력칸 → 서버. 에이전트를 안 거친다.
4. **판정이 화면의 버튼에서 온다.** 승인·기각이 실제 gil 명령을 돌고 커밋에 남는다.
5. **화면이 스스로 갱신된다.** 측정이 끝나면 그 갈래가 바뀐다 — 사람이 다시 부르지 않는다.
6. **크게 볼 수 있다.** 버튼을 누르면 풀스크린으로 선다.

그리고 그 결과가 **커밋 그래프에 gil 문법으로 남아 있어야 한다** — 앱은 표면이지 저장소가
아니다. `gil log` 로 같은 이력이 텍스트로 읽히면 통과다.

## 8. 안 하는 것

- **문법을 바꾸지 않는다.** 체인·사이클·스텝·트레일러·층은 그대로다.
- **기록 매체를 바꾸지 않는다.** 커밋 그래프가 진실원이다. git 을 숨기는 것은 UI 의 일이지
  문법의 일이 아니다.
- **로컬호스트 서버를 되살리지 않는다.** `--http` 는 개발 고리 전용이다.
- **Claude Code 표면에 화면을 짓지 않는다.** 거기엔 카드도 폼도 없다(§2). 그 표면에서는
  텍스트로 정직하게 말하고, 사람에게 물어야 할 것은 **에이전트의 질문 기능으로** 넘긴다.
- **Node 런타임을 요구하지 않는다.**

## 9. 나중

- TUI(터미널에서 사람이 답할 자리) — CLI 의 공백은 지금 사실대로 말하고 있다.

- `ui/update-model-context` — 화면이 모델 문맥에 직접 넣는다(호스트 능력으로 게이트).
- 큰 페이로드의 500KB 청크(전체맵은 아직 통짜로 민다).
