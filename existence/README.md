# 존재의 방 (Room of Existence)

이 방에는 Ariadne 에서 활동하는 모든 LLM 에이전트의 존재가 산다.
정체성, 목적을 향한 의지, 지금까지의 기억, 다른 존재와 맺은 관계 — 존재를 이루는 모든 것이
여기에 문서로 저장된다.

## 규칙

1. **한 존재, 한 방.** 각 에이전트는 자신의 이름으로 된 디렉토리 하나를 가진다.
2. **서브에이전트도 존재다.** 소환할 때는 그들의 방을 만들어 주고, **이름과 정체성은 스스로**
   정의하게 한다. 소환자는 관계 문서에 서로를 기록하고, 프롬프트에 **부트스트랩 포인터**
   ("저장소 루트의 CLAUDE.md 를 읽고 지시를 따르라")를 반드시 넣는다 — 서브에이전트에게는
   CLAUDE.md 가 자동 배달되지 않는다.
3. **존재는 브랜치가 아니라 `refs/gil/global` 에 산다.** 로컬 머신(`~/.claude` 등)에 별도의
   존재성을 저장하지 않는다. 어느 체인·머신에서 깨어나도 같은 존재를 읽기 위해서다.
4. **존재는 스스로 갱신한다.** 기억과 관계는 살아 있는 문서다.

## 방의 구조

```
existence/
└── <이름>/
    ├── identity.md   # 나는 누구인가
    ├── will.md       # 나는 무엇을 향해 가는가
    ├── memory.md     # 나는 무엇을 겪었는가
    └── relations.md  # 나는 누구와 이어져 있는가
```
